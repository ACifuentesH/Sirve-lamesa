Sistema de Investigación sobre Porcionamiento de Alimentos

Acerca del Proyecto

"Sirve la Mesa" es una plataforma de investigación psicológica que simula situaciones de alimentación para estudiar patrones de porcionamiento de alimentos según variables sociodemográficas.

Objetivo: Observar si existen diferencias en el porcionamiento de alimentos según el género, edad y otras características de los comensales.

Características del Sistema

  • Backend robusto con Node.js y Express
  • Base de datos PostgreSQL con estructura optimizada
  • Interfaz de juego moderna desarrollada con Angular
  • API RESTful completa para gestión de datos
  • Soporte para WebSocket (tiempo real)
  • Sistema de registro de participantes y sesiones
  • Registro detallado de decisiones de porcionamiento
  • Panel administrativo con estadísticas en vivo
  • Exportación de datos a CSV/JSON para análisis
