Prueba local de iframe — Simulador Sirve la Mesa

Arnés standalone para el criterio "verificado embebido dentro de un <iframe>" del issue #23 (A9). No requiere build ni dependencias: es HTML/CSS/JS plano.

Este arnés no sirve el build por sí mismo. Primero compila (cd angular-app && npx ng build --configuration production, la config de angular-app/angular.json ya deja base href="./") y sirve la carpeta angular-app/dist/sirve-la-mesa/ (o una copia suya en un subdirectorio anidado, para probar el criterio de rutas relativas) con cualquier servidor estático plano — por ejemplo npx http-server angular-app/dist/sirve-la-mesa -p 8099 — y pega esa URL arriba. También sirve para apuntar a una URL de Vercel ya desplegada. El snippet exacto de <iframe> recomendado para la Fundación está en docs/INTEGRACION-IFRAME.md; este arnés replica sus mismos atributos (title, sin allow porque no hace falta hoy, dimensiones mínimas).

Ancho completo
Pega la URL del simulador arriba y hacé clic en "Cargar en el iframe".
